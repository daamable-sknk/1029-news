## 2. 다운로드 절차 (매번 동일)

1. [빅카인즈](https://www.bigkinds.or.kr/) **로그인**
2. 뉴스검색 → 검색식 붙여넣기 (위와 **동일**하게 유지)
3. **기간**을 이번 배치 구간만 지정 (아래 체크리스트)
4. 결과 건수가 **≤ 20,000**인지 확인. 넘으면 기간을 더 잘게.
5. STEP 03 → **데이터 다운로드** → 미리보기 확인 → **엑셀 다운로드**
6. 파일명을 아래 규칙으로 바꿔 `raw/bigkinds/`에 저장
7. 이 문서 체크리스트에 건수·파일명 기록

### 파일명 규칙

```
bigkinds-YYYYMMDD-YYYYMMDD.xlsx
```

예: `bigkinds-20221029-20221031.xlsx` · `bigkinds-20240101-20241231.xlsx`

원본 파일명(`NewsResult_…`)을 유지해도 되지만, **기간이 파일명에 보이게** 바꾸는 걸 권장.

### 저장 위치

```
1029-news/
├── docs/계획-빅카인즈-순차다운로드.md
├── raw/bigkinds/                 ← 받은 xlsx 전부 여기
└── data/1029-articles.json       ← 병합 결과
```

## 5. 받은 뒤 (내가/스크립트가 할 일)

1. `raw/bigkinds/*.xlsx` 전부 읽기  
2. **뉴스 식별자**(또는 URL)로 중복 제거  
3. 칼럼 매핑 → 우리 목록:

| 빅카인즈 | 우리 |
|----------|------|
| 제목 | 기사제목 |
| 일자 | 발행날짜 |
| 기고자 | 기자명 |
| 언론사 | 발행처 |
| URL (있으면) | url |
| (비움) | 비고 |
| 다운로드·병합일 | 작성일 |
| (비움) | 작성자 |

4. 주제 태그는 목록 UI에 두지 않음 (검색·기간으로)  
5. `data/1029-articles.json` · xlsx · `index.html`에 반영  
6. 기존 Google/시드와 merge (식별자·URL·제목+일자로 중복 스킵)

## 6. 2차(선택) — 공공기록·특조위 좁히기

전량(~10만)이 부담이면, **같은 방식으로** 검색식만 바꿔 추가 다운로드:

```
(이태원) AND (특조위 OR 특별조사위원회 OR 특별법 OR 기록물 OR 회의록 OR 국가기록원 OR 중대본 OR 폐기)
```

기간 분할 규칙은 동일. 파일명에 `-record` 등 suffix.
