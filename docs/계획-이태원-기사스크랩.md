## 0. 역할 분담 (핵심)

| 누가 | 무엇을 |
|------|--------|
| **자동화 (우리)** | 검색·수집·URL 중복 제거 · 시드와 **같은 칼럼**으로 엑셀/CSV 생성 · 백필(2022.10.29~) + 이후 신규 갱신 |
| **담당자 (큐레이션)** | 엑셀을 받아서 필터·시트 분리·삭제 · **`비고`에 의미·사건·후속 메모를 자유롭게** · 연구·타임라인에 쓰기 |

자동화는 **발견·목록화**만 한다.  
의미 부여(이 기사가 왜 중요한지, 어떤 기록·사건과 연결되는지)는 **비고를 비워 둔 채** 사람에게 맡긴다.

팀 공용 Google Sheet에 자동으로 밀어 넣는 방식은 **필수가 아님**.  
우리가 만든 목록을 **엑셀로 내려받아** 각자 드라이브·한글·자기 시트에 가져가면 된다.

## 1. 목표·범위

### 1.1 목표
1. 시드와 **동일 8칼럼** 형식의 **다운로드용 엑셀**(+작업용 CSV)을 정기 생산.
2. 참사일(**2022-10-29**)부터 **소급 백필** + **이후 신규** 자동 수집.
3. URL 기준 **중복 제거**로 “이미 모은 것”을 다시 넣지 않음.
4. **`비고` = 항상 공란** (자동 태그·요지 넣지 않음).
5. 본문 전문 미러는 1차 범위 밖 (저작권·필요 시 별도).

### 1.2 도와 주는 일 / 안 하는 일

| 도와 줌 (자동화) | 담당자 몫 |
|------------------|-----------|
| 키워드로 기사 후보 긁기 | 쓸 것·버릴 것 고르기 |
| 제목·날짜·기자·매체·URL 채우기 | **비고**에 의미 쓰기 |
| 엑셀 파일 떨구기 | 탭 나누기·자기 목록에 merge |
| 매일/매주 신규만 추가 | 연구 서술·타임라인 반영 |

### 1.3 1차 수집 초점
| 순위 | 대상 |
|------|------|
| **P0** | 특조위·특별법·공공기록·회의록·폐기·수사기록 (시드와 동일) |
| P1 | 참사~국정조사·재판·유족·시민대책 (2022–2024 백필) |
| P2 | 추모·기억·아카이브 |
| P3 | 방송·영문 |

### 1.4 범위 밖
- 유료벽 전문 무단 저장, 대량 재배포.
- “이태원”만 있고 참사·특조·희생과 무관한 상권/맛집 기사 (제외 규칙).

## 2. 시드 형식 (따름) · 칼럼 규칙

### 2.1 스키마 — 사람용 엑셀은 이 8칸만

| 칼럼 | 자동화 | 담당자 |
|------|--------|--------|
| `기사제목` | ○ 채움 | 수정 가능 |
| `발행날짜` | ○ | |
| `작성자` (기자) | ○ 있으면 | |
| `발행처` | ○ 정규화 | |
| `url` | ○ **중복키** | |
| **`비고`** | **✗ 비움** | **자유 작성 · 의미 부여** |
| `작성일` | ○ 목록에 넣은 날 | |
| `작성자` (기입자) | ○ `auto` 등 | 수동 추가분은 본인 이름 |

시드처럼 탭 이름 = 테마(`특조위` …)는 **담당자가 엑셀에서** 나누거나, 우리가 쿼리별로 시트를 나눈 **초안 엑셀**을 줄 수 있음.  
초안 시트에도 **`비고`는 빈칸**.

### 2.2 왜 비고를 비우나
시드의 비고는 이미 “특별법 의결→제정”, “청문회 증언”처럼 **연구자가 붙인 의미**다.  
자동이 키워드를 비고에 넣으면 나중에 사람이 쓴 메모와 섞이고, “의미 부여” 공간이 사라진다.  
기계용 태그가 필요하면 **사람용 8칸 밖**(숨은 시트·별도 CSV)에만 둔다.

### 2.3 기계용 (다운로드 패키지 안, 큐레이션용 아님)

| 파일/칼럼 | 용도 |
|-----------|------|
| `url_canon` | 중복 판정 |
| `query_id` / `source` | 어떤 검색으로 들어왔는지 |
| `_meta.csv` 등 | 담당자가 안 봐도 되는 로그 |

## 3. 산출물: “받아서 가공하는 엑셀”

### 3.1 배포 단위
```
이태원-기사목록-YYYYMMDD.xlsx
  ├─ (예) 특조위     ← P0 쿼리 결과, 비고 공란
  ├─ (예) 전체       ← 또는 단일 시트
  └─ (선택) _수집로그
```

- 칼럼 순서·이름 = 시드와 **동일** → 기존 수동 목록에 **복사·붙여넣기** 가능.
- 내부 마스터는 CSV로 두고, **내보내기만 xlsx** (openpyxl 등).
- 담당 흐름: 다운로드 → 자기 폴더/드라이브에 저장 → 비고 작성·행 삭제·다른 시트와 merge.

### 3.2 우리가 돌리는 곳 (별도 자동화)
- 이 워크스페이스 `언론-스크랩/` + (예정) GitHub Actions / 로컬 스크립트.
- 팀 Sheet에 **강제 연동하지 않음**. 원하면 나중에 “엑셀을 드라이브에 올려 두기” 정도만.
